# Search Statistics

## Total searches
- Given a user visits the stats panel
- Then they see the total number of searches performed

## Top queries
- Given a user has performed multiple searches
- Then the stats panel shows top 10 most frequent queries

## Results by source
- Given search results have been displayed
- Then stats show a breakdown of how many results came from each source

## Search timeline
- Given a user has been using MeshHunt over multiple days
- Then a simple sparkline shows search activity over the last 30 days

## All data is local
- Given all statistics
- Then they are computed from localStorage only
- And no data is sent to any server for tracking
